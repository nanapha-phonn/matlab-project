# 📚 About This Repository

This repository contains MATLAB lessons, exercises, projects, and simulations for learning:

- MATLAB programming

# 💻 Example MATLAB Code

```matlab
clc
clear
close all

x = 0:0.1:10;
y = sin(x);

plot(x,y,'LineWidth',2)
grid on

title('Sine Wave')
xlabel('x')
ylabel('sin(x)')
```
